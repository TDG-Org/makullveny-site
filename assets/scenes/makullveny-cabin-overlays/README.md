# Makullveny cabin decorative overlays

Transparent PNG overlays in the same palette as the cabin scene. All are designed to remain legible when placed at 30% opacity over a near-black background.

| Asset | Canvas | Placement |
| --- | --- | --- |
| `bough-top-left.png` | 1000×560 | top-left corner |
| `bough-top-right.png` | 1000×560 | top-right corner |
| `bough-bottom-left.png` | 1000×520 | bottom-left corner |
| `bough-bottom-right.png` | 1000×520 | bottom-right corner |
| `ivy-hanging.png` | 320×760 | hangs from the top edge |
| `pine-cones-ground.png` | 620×260 | rests on a lower ground edge |

Use the PNGs directly; each background is transparent.
